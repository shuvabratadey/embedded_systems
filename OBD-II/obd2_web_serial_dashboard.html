OBD-II Bluetooth Debug Console

Connect to a Bluetooth serial OBD-II adapter such as an ELM327-compatible device, inspect live vehicle data, read diagnostic trouble codes, decode responses, and send raw AT / OBD commands with explanations.

Connection

Web Serial
Browsers cannot silently list every Bluetooth device on your laptop. Use Request Port to choose your OBD-II Bluetooth serial adapter if it exposes a serial profile.
Recommended sequence after pairing adapter with the laptop: pair device in OS → open this page in a Chromium browser → Request Port → Connect → Initialize adapter.

Adapter Setup

ELM327
Initialization sends common ELM327 commands such as ATZ, ATE0, ATL0, ATS0, ATH1, and ATSP0.

Custom Command

AT / OBD-II
Examples: 010C engine RPM, 010D vehicle speed, 03 stored trouble codes, 0902 VIN, ATDP current protocol.

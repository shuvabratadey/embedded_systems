OBD-II Diagnostic Suite

Choose how you want to interact with OBD-II — connect to your real vehicle over serial/Bluetooth, or explore a fully featured software simulator.

Test My Vehicle
Connect a physical ELM327-compatible OBD-II adapter to your vehicle and read real-time data directly through the browser.
  • Bluetooth & USB serial adapters (Web Serial API)
  • Live RPM, speed, coolant temperature, voltage
  • Read and clear Diagnostic Trouble Codes (DTCs)
  • Decode VIN and raw OBD-II responses
  • Continuous PID polling with analysis table
Run Simulation
Use the software simulator to explore OBD-II protocol responses without any hardware. Perfect for learning and development.
  • Simulated ELM327 adapter & ECU responses
  • Car and bike vehicle profiles with editable data
  • Inject DTC fault codes and test decoders
  • AT command console with live terminal
  • No hardware required — works offline

The Live Vehicle interface requires a Chromium-based browser (Chrome / Edge) for Web Serial API support. The Simulator works in any modern browser — no hardware needed.
